🧭 RUTA GUIADA • PYTHON + HTML

Hoja de Ruta: Desarrollo Web con Python

Aprende a construir aplicaciones web reales desde cero uniendo la estructura de HTML con el poder del backend en Python. Sigue cada fase en orden usando los recursos de nuestro Legajo.

1
FASE 1 • FUNDAMENTOS

Bases de la Estructura Web y Lógica de Programación

Antes de conectar ambos mundos, domina cómo se construye el esqueleto de una página web y cómo pensar como programador con variables, condicionales y bucles.

🌐 Qué aprender de HTML:
  • Etiquetas de texto, enlaces, imágenes y listas.
  • Estructura básica (<html>, <head>, <body>).
🐍 Qué aprender de Python:
  • Tipos de datos, variables y operadores.
  • Condicionales (if/else) y ciclos (for/while).
📚 Dónde estudiarlo (Legajo Básico): W3Schools, Cisco Networking Academy, Coddy.tech o freeCodeCamp.
🎯 Meta práctica: Crear una página personal estática en HTML y un programa de consola en Python (ej. calculadora o menú interactivo).
2
FASE 2 • INTERMEDIO

Formularios Web y Programación Orientada a Objetos (POO)

Aprende a capturar datos del usuario en el navegador mediante formularios y a modelar esa información usando clases y objetos en Python.

🌐 Qué aprender de HTML:
  • Formularios (<form>, <input>, <textarea>).
  • Tablas y HTML semántico (<header>, <main>, <aside>).
🐍 Qué aprender de Python:
  • Listas, diccionarios y manejo de errores.
  • Clases, objetos, atributos y métodos (POO).
📚 Dónde estudiarlo (Legajo Intermedio): MDN Web Docs, El Libro de Python, Platzi o Cisco Python Essentials 2.
🎯 Meta práctica: Diseñar un formulario de registro en HTML y crear las clases en Python que representen esos usuarios y cursos.
3
FASE 3 • UNIÓN FULL-STACK

Conectar HTML y Python con Flask y Plantillas Jinja2

Aquí es donde ambos lenguajes trabajan juntos: Python procesa la lógica en el servidor y envía datos dinámicos hacia tus plantillas HTML.

🌐 Qué aprender en Plantillas:
  • Herencia con base.html y bloques dinámicos.
  • Mostrar variables y bucles dentro del HTML con Jinja2.
🐍 Qué aprender en el Servidor:
  • Rutas HTTP (GET y POST) con Flask.
  • Recibir datos de formularios (request.form) y sesiones.
📚 Dónde estudiarlo (Legajo Avanzado): Documentación oficial de Flask, Platzi Escuela de Python o nuestras clases en Acervus.
🎯 Meta práctica: Construir una aplicación web dinámica donde los formularios HTML guarden datos procesados por Python.
4
FASE 4 • PRODUCCIÓN

Persistencia en Base de Datos, SEO y Despliegue

Lleva tu proyecto al mundo real guardando la información permanentemente en la nube y optimizando tu HTML para buscadores.

🌐 Qué aprender de HTML Avanzado:
  • Metadatos SEO y accesibilidad web (ARIA).
  • Optimización de estructura y rendimiento.
🐍 Qué aprender de Backend Avanzado:
  • Conexión a bases de datos (MongoDB / SQL).
  • Despliegue en la nube (Render / GitHub).
📚 Dónde estudiarlo (Legajo Avanzado): Guía SEO de Google, MDN Accesibilidad y FastAPI/Flask Docs.
🎯 Meta final: Publicar tu propia plataforma web funcional en internet (¡como Acervus!).
